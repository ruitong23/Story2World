# Story2World Desktop

本地桌面世界模拟程序。支持两条准备流程：根据用户设定构建项目，或从小说文本抽取世界；两者共用同一个模拟界面与运行引擎。

## 桌面入口

| 启动文件 | 界面名称 | 用途 |
| --- | --- | --- |
| `00_setting_studio.bat` | 设定工作台 | 与模型讨论设定、准备背景知识、构建人物和世界，管理独立项目 |
| `02_novel_world_builder.bat` | 小说世界准备 | 导入小说 TXT，选择抽取范围和分块参数，生成当前小说数据库 |
| `03_simulation_launcher.bat` | 模拟项目选择器 | 选择小说数据库或设定项目，进入共用模拟器 |

`01_install_dependencies.bat` 用于安装依赖，不是模拟入口。

工作台的“导入 TXT”将文件作为对话输入；长篇小说的分块抽取应使用“小说世界准备”。工作台构建完成后可以直接进入模拟，也可以之后从项目选择器打开。

## 安装与模型配置

1. 安装 Windows Python 3.10 或更高版本，包含 Tcl/Tk，并把 Python 加入 PATH。
2. 运行 `01_install_dependencies.bat`。
3. 启动一个 OpenAI-compatible 模型服务。
4. 在界面选择实际模型并配置服务地址、认证信息；也可将 `settings.example.json` 复制为 `settings.json` 后填写。`local-model` 是占位名称，需要替换为服务提供的模型 ID。
5. 从上述任一准备入口开始；首次使用没有预置世界或人物。

默认服务地址为 `http://localhost:1234/v1`。模型服务如要求认证，需要填写其真实密钥。

小说流程与模拟器还支持 `NOVEL_LLM_BASE_URL`、`NOVEL_LLM_MODEL` 和 `NOVEL_LLM_API_KEY` 环境变量；工作台使用界面保存的模型配置。

## 数据与通用规则

- 小说抽取结果保存在 `db/`。
- 可复用背景知识保存在 `background_library/`。
- 用户保存的设定与独立项目保存在 `scenario_library/`。
- 模型调用用量记录在运行时产生；模型配置保存在 `settings.json`。

这些内容均由使用者在运行时创建，本仓库不携带小说、设定、背景库、人物资料、模拟存档、聊天、模型输出或历史测试记录。

作品、人物、角色关系、能力和世界规则来自当次输入及其资料。候选步骤只在当前设定要求时启用。开场地点、时间和活动依照当前项目；职业身份不默认解释为伪装。未指定叙事视角时默认采用玩家第一人称有限视角。

背景检索使用公开网页、Wikipedia 和 Wikidata 等来源，结果依赖可访问性与证据覆盖。资料缺失保留未知；已有引用不等于所有事实和角色表现都已完整验证。

## 开发与提交

直接维护本目录的 Python 源码。发布仓库只保留运行源码、启动脚本、必要配置示例和文档。测试脚本、测试输入、固定输出及验证报告均在仓库之外执行和保存。

`.gitignore` 默认排除根目录的所有文件和目录，只放行逐项列出的源码、启动脚本、配置示例和文档。新增源码时需要同步更新放行列表。即使在本仓库运行模拟，通常的 `git add .` 也不会纳入生成数据；不要使用强制添加命令提交私人文件。

本仓库只包含桌面程序。许可见 `LICENSE`。
